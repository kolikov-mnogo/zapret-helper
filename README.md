# 🛠️ Zapret Helper

> **Это помощник по настройке Zapret. Самим Zapret этот проект не является.**

## ⚠️ Важно

Друзья, в сети появилось большое количество различных «готовых сборок» Zapret, которые якобы уже настроены и готовы к работе.

Будьте внимательны при скачивании подобных файлов — вы не всегда можете знать, что именно находится внутри сторонней сборки.

Именно поэтому я создал **Zapret Helper** — небольшой вспомогательный инструмент, который помогает работать с **оригинальным проектом Zapret**, не подменяя его собственной сборкой.

### 🔐 Что важно знать

**Zapret Helper ≠ Zapret**

Helper не является самим Zapret и не заменяет оригинальный проект.

Я рекомендую использовать **только оригинальный Zapret от Flowseal** и скачивать его из официального репозитория:

## 🚀 Что такое Zapret Helper?

**Zapret Helper** — сторонний помощник для более удобной настройки и использования оригинального Zapret.

Проект создан для пользователей, которым не хочется разбираться во всех настройках вручную и которые хотят получить удобный набор дополнительных инструментов в одном месте.

### Возможности

* ⚙️ Помощь с настройкой Zapret
* 📦 Готовые пресеты
* 📋 Управление списками IP-адресов и доменов
* ➕ Добавление собственных адресов
* 🔄 Дополнительные инструменты для работы с Zapret
* 🚀 Настройка автоматического запуска
* 🔍 Проверка состояния
* 💬 Встроенная информация и помощь

---

## 📦 Готовые пресеты

В проекте предусмотрены готовые наборы для популярных сервисов:

**Telegram · Steam · Twitch · Spotify · WhatsApp · GitHub · Roblox · Epic Games · Minecraft · VK · Twitter/X · Instagram · Facebook · Netflix · Deezer**

Также можно добавлять собственные IP-адреса и домены.

> ⚠️ Сетевые адреса сервисов могут изменяться. Поэтому содержимое пресетов со временем может потребовать обновления.

## 🖥️ Как это работает?

Принцип максимально простой:

**Оригинальный Zapret → Zapret Helper → удобная настройка**

Helper используется **вместе с оригинальным Zapret**, а не вместо него.

Сам Zapret скачивается отдельно из репозитория Flowseal.
