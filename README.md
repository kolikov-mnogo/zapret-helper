# zapret-helper
Это помощник по настройке запрета но это не является самим запретом
Друзья, в сети появилось много «готовых сборок» Zapret, которые якобы уже настроены для работы. Будьте бдительны: часто такие файлы небезопасны. Я создал этого помощника, чтобы вы могли настроить всё правильно и безопасно самостоятельно. Я поддерживаю только оригинальный проект от разработчика Flowseal. разработчик настоящего запрета это Flowseal вот ссылка на сам запрет https://github.com/Flowseal/zapret-discord-youtube/releases
